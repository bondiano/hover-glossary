# hover-glossary

Клиентский плагин с постоянной установкой для [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness): наведение курсора на слово в тексте сообщения пользователя или ассистента показывает всплывающую подсказку: **1 → N толкований**.

Например, `WHO` показывает «1. Всемирная организация здравоохранения (аббревиатура); 2. кто (местоимение)». Словарь и поиск работают в браузере: плагин не отправляет запросы к модели, не регистрирует инструменты, не добавляет системный промпт и не создаёт отдельную панель словаря или диагностическую карточку при запуске.

Это русскоязычный форк [AlyceStocking/hover-glossary](https://github.com/AlyceStocking/hover-glossary); дальнейшая разработка ведётся в [bondiano/hover-glossary](https://github.com/bondiano/hover-glossary).

## Текущая версия и совместимость

Текущая версия — **1.2.0** (русское издание). В словаре 212 терминов и 236 толкований: объяснения и ключи терминов переведены на русский, а английские и технические ключи (`WHO`, `API`, `token`, `KV cache`, `vLLM`, `Ascend`, `GLM-5.3-Flash` и другие) остаются как есть. Поиск целиком выполняется в браузере.

В исходном проекте пакет проверен на Harness CLI `0.1.5-rc.1` и клиентском компоненте `0.1.5-rc.2`, а также на DSH Desktop `0.2.0-rc.2` — для Desktop проверены только установка пакета и регистрация. В этом форке проверена совместимость с API DSH `0.2.2-rc.3`: контракт загрузчика клиентских модулей, слот `shell.overlay` и маркеры `data-chat-flow-kind`. Сам эффект наведения проверяется вручную в браузере.

## Установка и обновление

Установите плагин встроенной командой dsh (после установки он появится в разделе «Настройки → Плагины», где его можно включать, отключать и удалять):

```bash
dsh plugin --profile desktop add github:bondiano/hover-glossary
```

Этот форк не публикует пакет в npm, поэтому устанавливайте плагин из исходников на GitHub.

Пользователям Desktop: после установки полностью закройте и снова откройте приложение. Пользователям Web: замените `desktop` на `web`, перезапустите `dsh web` и откройте страницу по аутентифицированному URL, который печатается при запуске. Если обновился только браузерный бандл, обычно достаточно обновить страницу; после изменения манифеста или состава перезапустите Harness и проверьте результат. Пакет и словарь лежат на диске и перезагружаются после перезапуска.

> Не устанавливайте плагин копированием в `node_modules` и ручной правкой `cordis.patch.yml`: так он запустится, но, поскольку не является pnpm-зависимостью профиля, интерфейс управления плагинами его не покажет. Не заменяйте установку в профиль временными `cordis_define` / `cordis_run`, живущими только в памяти процесса.

## Обновление словаря

Единственный источник словаря — `src/seed-data.mjs`:

```js
TERM: [
  { text: 'первое толкование', kind: 'аббревиатура', weight: 100 },
  { text: 'второе толкование', kind: 'местоимение', weight: 10 },
],
```

Чем больше `weight`, тем выше толкование в списке; при равном весе сохраняется порядок регистрации. После правок запустите `node scripts/build-client.mjs` и `node test/run.mjs`, затем переустановите или обновите плагин и проверьте результат. Полный порядок действий — в [навыке glossary-mapping](.dsh/skills/glossary-mapping/SKILL.md).

## Поведение и границы

- Всплывающая подсказка показывает в шапке термин и количество толкований по-русски («1 значение», «2 значения», «5 значений»); ниже идёт нумерованный список с подписью категории (kind).
- Регистр, ширина символов и пунктуация не важны: `who`, `Who` и вариант в полноширинных символах попадают в один термин. При этом `WHO` не находится внутри `WHOLE`, а `токен` — внутри `токенизатор`.
- Побеждает самое длинное совпадение. Составные термины срабатывают с первого слова: при наведении на `United` в `United Nations` или на первое слово в `скрытое состояние` подсказка показывает весь термин.
- Учитывается только текст сообщения пользователя и ассистента; боковая панель, настройки, кнопки, ссылки и поле ввода пропускаются. Сообщением пользователя считается уже отправленное сообщение.
- Поиск ограничен одним текстовым узлом DOM: слово или фраза, разорванные по нескольким стилевым узлам, не склеиваются.
- Глобальный `globalThis.__hoverGlossaryDiag__` доступен в консоли и выводит самопроверку: количество слов и толкований, пробу, классификацию и токен.

## Разработка и проверка

16 тестов Node покрывают словарь, синхронизацию артефактов, контракт клиентского бандла и путь mousemove. Отдельный скрипт `test/browser.mjs` проверяет активацию в работающем Harness и существующие сообщения чата, а также выборку из пяти слов в зонах пользователя и ассистента. Подробности — в [руководстве по разработке](DEVELOPMENT.md).

Исходный проект проверен на локальном Harness CLI `0.1.5-rc.1`, клиентском компоненте `0.1.5-rc.2` и в Edge; для других версий проверяйте DOM-маркеры чата и контракт слотов. В этом форке совместимость с DSH `0.2.2-rc.3` проверена на уровне API, а эффект наведения — вручную в браузере.

## Распространение и включение в каталог

Тема GitHub `dsh-plugin` используется для включения в каталог dshfind; после добавления темы подождите обновления каталога. Установка из GitHub и публикация в npm — независимые каналы; этот форк npm-пакет не публикует. Перед любой публикацией запускайте `npm test` и `npm pack --dry-run` и проверяйте, что `lib/client.js` пересобран после правок словаря. Проект распространяется по лицензии MIT, см. [LICENSE](LICENSE).
